# VisionCane 0.4.0 — גרסת הדגמה

אפליקציית Flutter לאנדרואיד ולאייפון לתיאור קולי של עצמים מוכרים מתוך מצלמה, בעיבוד במכשיר. זהו אב־טיפוס להצגה מבוקרת ולקבלת משוב; אין בו עדיין מערכת להנחיית הליכה או גילוי אמין של כל המכשולים.

## הפעלה

התחל במסך **הדגמה**: הפעל זיהוי, המתן לטעינה ואז הפעל קול עברי. אפשר לבחור תיאור אוטומטי או ללחוץ **תאר עכשיו**. **עצירת הכול** עוצרת מצלמה וקול. במעבר לרקע המצלמה והקול נעצרים, ואין חידוש צילום אוטומטי.

בהפעלה הראשונה נדרש אינטרנט להורדת מודל הראייה וקול עברי מותקן במערכת. לאחר הכנה יש לבדוק פתיחה מחדש במצב טיסה עם Wi-Fi כבוי. בקוד אין שירות זיהוי ענני או שמירת תמונות. ימין ושמאל מתייחסים לתמונת המצלמה האחורית, ולא לכיוון הגוף.

## מה נכלל

- מסך הדגמה בעברית עם כפתורים גדולים, ניגודיות גבוהה, כותרות סמנטיות, מצב מצלמה נגיש ותמיכה בהגדלת גופן. נדרשת בדיקת TalkBack ו-VoiceOver במכשירים אמיתיים.
- זיהוי YOLO26n של קטגוריות מוכרות, סינון לפי ציון ומיקום בשליש התמונה.
- קול עברי מותקן, בחירת מנוע מקומי, בדיקת תוצאת בחירת הקול, ביטול הכנה בעת עצירה, וזמן המתנה מוגבל למשפט.
- תיאור אוטומטי לזיהוי יציב בציון 65% לפחות במשך 700ms ושלוש תצפיות לפחות; מרווח 3.5 שניות בין הכרזות ו-12 שניות לפני חזרת קטגוריה באותו צד. זו מדיניות החלקה, ולא מעקב זהות אחרי עצם.
- תיאור לפי בקשה של עד שלושה זיהויים עדכניים; אין הכרזה שהדרך פנויה כשלא זוהה דבר.
- מסך כלי בדיקה נפרד: סף זיהוי, בקשת GPU, מדידת ביצועי SDK וניסוי עומק חזותי נפרד.
- יומן בדיקות ידני הנשמר במכשיר, סיכום לפי גרסה/מצב/מקרה, והעתקה או שיתוף JSON כקובץ דרך בוחר השיתוף של המכשיר.
- דוח אבחון עם מנועי קול, מטא־דטה של קולות עבריים, מצב מצלמה ואירועים אחרונים, ללא תמונות או הקלטות.
- מסלול Codemagic מהיר לאנדרואיד בלבד, ומסלול נפרד לבדיקה של שתי הפלטפורמות.

## תיקון ההקראה מגרסה 0.2

בקוד המקור של flutter_tts 4.2.5 באנדרואיד, network_required מוחזר כמחרוזת `"0"` לקול מקומי וכמחרוזת `"1"` לקול דורש רשת. הקוד הישן בדק false, המספר 0 או המחרוזת false, ולכן דחה את הקול המקומי התקין. גרסה 0.4 מקבלת גם `"0"` ומכילה בדיקת רגרסיה לתגובה הזאת. קולות דורשי רשת או עם מטא־דטה לא ידועה אינם משמשים כחלופה אוטומטית. פעולה פיזית של התיקון עדיין דורשת בדיקה בטאבלט.

## בנייה

Flutter **3.47.7**, Dart 3.13.5 ו-Node 20 ומעלה. גרסאות התלויות הישירות מקובעות ב-pubspec, ואת pubspec.lock יש לשמור לאחר פתרון התלויות. קובצי Android/iOS נוצרים בהתאם ל-SDK באמצעות כלי ההכנה. מינימום Android API 24, iOS 15. לבנייה מקומית נדרשים Android SDK ו-JDK מתאימים.

```sh
node tool/check_layout.mjs
node --test tool/native_config.test.mjs
node tool/bootstrap.mjs
flutter analyze
flutter test --reporter expanded
flutter build apk --debug
```

ב-Codemagic בחר `android-demo` לקבלת app-debug.apk. בחר `verify-mobile` רק כשצריך גם השוואת Android Release וקומפילציית iOS. פלט iOS ללא חתימה אינו ניתן להתקנה באייפון. docs/codemagic-testflight.yaml הוא מסלול אופציונלי שמצריך חשבון Apple וחתימה שהוגדרו בנפרד.

ראו [התקנה ועדכון](docs/INSTALL.md), [מדריך הדגמה לארגון](docs/DEMO_GUIDE.md), [רישום ניסויי שטח](docs/FIELD_TEST.md) ו[מצב האימות](docs/STATUS.md).

## מצב יכולות ומגבלות

גרסה 0.1 רצה לפי דיווח המשתמש על SM-X510 עם קצב מנוע חציוני כ-11.7 FPS. גרסה 0.2 נבנתה בענן, ו-Debug נפתח בטאבלט; Release נסגר בעלייה, ללא לוג המוכיח סיבה. תיקון הקול ומסך ההדגמה החדשים שייכים לגרסה 0.4. המדדים ההיסטוריים אינם תוצאות של 0.4.

אין מדידת מרחק מאומתת, מסלול הליכה, גילוי מובטח של כבלים, רגליים דקות, בורות, מדרגות או ענפים. מצב העומק משתמש במודל נפרד, אינו רץ במקביל לזיהוי, ואינו מייצר התרעת סכנה. אין מדידת זמן צילום-עד-הקראה, פריימים שנפלו, חום וסוללה, או ניסוי פיזי באייפון. אין להציג את הגרסה כמוצר מוגמר להליכה עצמאית.

## פרטיות ותלויות

קוד האפליקציה אינו שומר או מעלה פריימים ואינו מבקש מיקרופון או מיקום. תוצאות ידניות נשמרות באחסון הפרטי; הסרת האפליקציה עלולה למחוק אותן. דוח ביצועים ואבחון נמצאים בזיכרון עד יצוא. יצוא שומר JSON במטמון ופותח בוחר שיתוף, ורק המשתמש בוחר יעד. קובצי יצוא ישנים בני יום ומעלה נמחקים מהתיקייה הייעודית בעת יצוא נוסף. אין שליחה אוטומטית.

התלויות והמודלים כפופים לרישיונות שלהם; ראו docs/THIRD_PARTY.md לפני הפצה. חבילת המקור אינה כוללת משקלי מודלים, מפתחות חתימה או אישורי חשבון.
