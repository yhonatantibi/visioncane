# VisionCane 0.5.0 — תיאור עצמים ומרחב מתמונה משותפת

אפליקציית Flutter לאנדרואיד ולאייפון. גרסת ניסוי שמחברת זיהוי עצמים, אומדן עומק וסיווג מבנה המרחב, ומקריאה את התוצאה בעברית. נדרשת בנייה ובדיקת מכשיר לגרסה זו לפני שימוש בהדגמה.

## מה השתנה מ-0.4

במסך הדגמה המתג ״עצמים, מרחק ומבנה ביחד״ מופעל כברירת מחדל. מצלמה אחת מפיקה תמונה וזיהויי עצמים מאותה תמונה; אותה תמונה מועברת למודל מרחק ולמודל מבנה. אין איסוף מרחק מתמונה מאוחרת והדבקתו לזיהוי מתמונה מוקדמת.

ההקראה כוללת שם, אחד מתשעה אזורים בתמונה, ואומדן מרחק כשיש נתון תקין. לדוגמה: ״כיסא משמאל בתמונה, בחלק האמצעי, במרחק משוער של שני מטרים״. דלתות, קירות, רצפה, תקרה, חלונות ומדרגות מתוארים רק אם קטגוריות אלה נמצאות במטא־דטה של מודל המבנה ותוצאתו תומכת בכך.

״תאר עכשיו״ מקריא עד ארבעה פרטים, עם פרט מבני אחד כשזוהה. הרשימה מציגה את כל הפרטים שהתקבלו בניתוח. תיאור אוטומטי דורש הופעה בשתי תוצאות משולבות עוקבות, עם רווח של חמש שניות לאחר משפט וצינון חזרה של 12 שניות לקטגוריה באזור תמונה. אין מעקב זהות אחרי עצמים.

אם אין אומדן תקין נאמר ״המרחק אינו זמין״. נתונים ישנים מ-2.5 שניות מרגע הגעת תמונת האירוע אינם מוצגים או מתחילים הקראה. זה אינו זמן צילום-עד-הקראה מדוד; עצם ההקראה נמשך בזמן.

## מודלים ופעולה מקומית

- yolo26n — זיהוי קטגוריות עצמים מוכרות.
- yolo26n-depth — אומדן מונוקולרי של מרחק במטרים לפי פורמט התוסף.
- yolo26n-sem — סיווג אזורים בתמונה לפי קטגוריות המודל; מיפוי המספרים נלקח ממטא־דטה, ולא מטבלה משוערת.

שלושת המודלים פועלים על המכשיר. בהפעלה הראשונה יש הורדה של המודלים. תמונות מועברות בין רכיבי העיבוד בזיכרון ואינן נשמרות או מועלות בקוד האפליקציה. אין בקשת מיקרופון או מיקום. אחרי הכנה צריך לבדוק פתיחה מחדש במצב טיסה ו-Wi-Fi כבוי.

## ביצועים

זיהוי העצמים ממשיך בזרם המצלמה, בעוד ניתוח משולב מתחיל לכל היותר פעם בשנייה. מודלי העומק והמבנה מעבדים את אותה תמונה בזה אחר זה כדי לצמצם תחרות על GPU. זו פעולה משולבת בזמן שימוש אחד, ואינה הבטחה שכל פריים מעובד בשלושה מודלים או שהמודלים רצים בו-זמנית בחומרה.

יש רק תמונה משולבת אחת בעיבוד, ללא תור מתארך. תוצאות שהגיעו אחרי עצירה, רקע או הפעלת מצלמה חדשה נדחות. קצב העדכון עם שלושה מודלים ב-SM-X510 וב-iPhone 13 עדיין לא נמדד. מדד FPS של גלאי העצמים אינו קצב הניתוח המשולב. אבחון מציג בנפרד את מספר הניתוחים וזמן אירוע-עד-השלמה.

אם ניתוח איטי מדי, יוצג שאין תיאור משולב עדכני. אפשר לכבות את המתג כשהמצלמה כבויה ולחזור לזיהוי העצמים הקודם. ראו docs/SPATIAL.md.

## מגבלות משמעותיות

המרחק הוא אומדן מודל לא מכויל, ולא מדידת חיישן או מרחק בטוח להליכה. דגימה מתוך מרכז תיבת עצם עשויה לכלול רקע או עצם אחר; דגימות מעטות, שגויות או מפוזרות מדי נדחות, אך אין בכך הבטחה לדיוק.

המיקום הוא בתמונה של המצלמה האחורית, בתשעה אזורים. אין כיוון ביחס לגוף, זווית מדויקת או מפה של המבנה. זיהוי דלת אינו מוכיח שהיא פתוחה, ניתנת למעבר, כניסה או יציאה. זיהוי רצפה אינו אומר שהמסלול פנוי. אין עדיין זיהוי אמין של כל מכשולי הדרך, בורות או כבלים, ואין הנחיית הליכה עצמאית.

## קול וממשק

נשמר תיקון הקול מ-0.4: flutter_tts מחזיר network_required כמחרוזת 0/1, והקוד מקבל מחרוזת 0 ודוחה קול רשת וערך לא ידוע. קול נבחר מתוך קולות מותקנים. הפעלה, עצירת הכול, תיאור לפי בקשה, טופס בדיקה, דוחות ואבחון זמינים בעברית. נדרשות בדיקות TalkBack ו-VoiceOver פיזיות.

## בנייה והתקנה

Flutter 3.47.7, Dart 3.13.5, Node 20 ומעלה. התלויות הישירות וקובץ pubspec.lock מקובעים. קובצי Android/iOS נוצרים ב-bootstrap. מינימום Android API 24 ו-iOS 15.

```sh
node tool/check_layout.mjs
node --test tool/native_config.test.mjs
node tool/bootstrap.mjs
dart tool/domain_smoke.dart
dart tool/spatial_smoke.dart
flutter analyze
flutter test --reporter expanded
flutter build apk --debug
```

ב-Codemagic בחר main ומסלול android-demo לאחר העלאת התוכן המעודכן. יש לשמור על lib/domain, lib/services, lib/screens, test, tool ו-docs. אין להעלות ZIP או תיקייה עוטפת סביב pubspec.yaml. פלט Android להתקנה הוא app-debug.apk. פלט iOS ללא חתימה אינו מתקין אפליקציה באייפון; נדרשים חשבון וחתימה מתאימים.

## בדיקה לפני הצגה

פעל לפי docs/SPATIAL.md למדידת מרחקים מול סרט מדידה, שיוך עצמים לאזורים, קירות ודלתות, פתחים שאינם יציאה ובדיקות רקע/עצירה. בדוק במיוחד שהמערכת אינה מקריאה נתון ישן אחרי הזזת מצלמה. יש לתעד גם החמצות, מרחק שגוי ותיוג מבני שגוי. אין להסתמך על דוגמה מוצלחת אחת.

יומן הבדיקות נשמר במכשיר וניתן להעתקה או שיתוף כ-JSON. מצב integrated_scene נשמר בנפרד מ-detect ומ-depth_experiment. הסרת אפליקציה יכולה למחוק דוחות ומודלים; יצא דוחות חשובים קודם.
