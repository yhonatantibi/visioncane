# מצב גרסה 0.4.0

עודכן ב-21.10.2026.

## מה קיים

חבילת מקור מלאה עם מסך הדגמה בעברית, זיהוי YOLO26n, תיקון בחירת קול עברי מקומי, תיאור לפי בקשה/אוטומטי, עצירה, מניעת תוצאות ישנות, דוח אבחון, יומן בדיקות ושיתוף קובצי דוח. כלי מדידה וניסוי עומק זמינים בנפרד. חומרת המקל והתרעות מרחק אינם חלק מהגרסה.

## מה אומת בסשן זה

- נמצא בקוד המקור הרשמי של flutter_tts 4.2.5 שהשדה network_required מוחזר כמחרוזת 0/1. הקוד הישן לא קיבל מחרוזת 0. התיקון מקבל אותה ודוחה קול רשת או ערך לא ידוע.
- הותקנה סביבת Flutter 3.47.7 עם Dart 3.13.5 ונפתרו התלויות. pubspec.lock נכלל בחבילה.
- שבע בדיקות Node להגדרות Android/iOS עברו; בדיקת מבנה הפרויקט ובדיקת תחביר כלי bootstrap עברו.
- שמונה בדיקות עשן של לוגיקת Dart הורצו בהצלחה ללא Flutter: מטא־דטה של קול, דחיית רשת, התייצבות וצינון, כיוונים, גבולות מדידה ושימור תוצאות ידניות. נבדק גם פענוח תחביר של 17 קובצי Dart ללא שגיאת תחביר. אלה אינן בדיקות מנוע, ממשק או מכשיר.
- flutter analyze עבר ללא שגיאות בעותק הבדיקה, לפני התוספת האחרונה של הודעת תקיעה ורישיונות רכיבים. לא מורחבת מכך טענה שהגרסה האחרונה עברה את כל הבדיקות.
- נכתבו 34 בדיקות Flutter. הרצתן והפקת APK מקומית נחסמו במנגנון האישור האוטומטי עקב ניסיון טלמטריה אל dc.services.visualstudio.com, גם אחרי ניסיון ביטול דיווח. לא אושר שיתוף המטא־דטה ולא הושלמה ההרצה.

## מה עדיין לא אומת

אין בסשן זה APK תקין של 0.4, הרצת בדיקות Flutter מלאה, בנייה בענן של 0.4, או בדיקה פיזית שלה. לא בוצעו בדיקת TalkBack/VoiceOver, קול מתוך האפליקציה בטאבלט, זמן צילום-עד-הקראה, מדידת דיוק, חום וסוללה או פעולה פיזית באייפון. אין לטעון שהמערכת הסופית כבר מוכנה לשימוש עצמאי.

## עדויות קודמות

לפי דיווח המשתמש, גרסה 0.1 זיהתה עצמים ב-SM-X510 עם קצב SDK חציוני כ-11.7 FPS. גרסה 0.2 נבנתה בענן; Debug נפתח בטאבלט, ו-Release נסגר בעלייה ללא לוג. במערכת ההפעלה הושמע קול עברי גם במצב טיסה ו-Wi-Fi כבוי; בחירת הקול באפליקציה נכשלה, והסיבה שתוקנה מתועדת לעיל. אלה אינם תוצאות בדיקה של 0.4.

## הצעד הנדרש

המקור נשמר מקומית; לא בוצע push ל-GitHub. קריאת המאגר הצליחה, אך ניסיון בדיקת הרשאת כתיבה נכשל בהרצת מנהל האישורים בסביבה. חבילת המקור המלאה כוללת גם מסלול GitHub Actions אופציונלי, שאינו פעיל עד העלאתו למאגר והרצתו בענף demo-0.4.0 או ידנית.

להריץ android-demo ב-Codemagic על מקור 0.4 המעודכן. השער כולל flutter analyze ו-flutter test לפני הפקת app-debug.apk. לאחר מכן להתקין ולבצע את הכנת ההדגמה ב-DEMO_GUIDE.md. רק לאחר שהבדיקות האלו עוברות אפשר לאשר הדגמה מבוקרת של תיאור עצמים בפני משתמשים. פיתוח התרעות מכשולים, עומק מספרי וכוונת מצלמה ביחס לגוף הוא שלב המשך נפרד.
